# Análise de Vinhos 🍷

Este projeto realiza uma análise exploratória de dados de vinhos utilizando **Python**, **Pandas**, **Matplotlib** e **Seaborn**.  
Ele foi desenvolvido com um dataset fictício, mas pode ser facilmente adaptado para datasets reais (como os disponíveis no Kaggle).

---

## 📂 Estrutura do Projeto
- `main.py` → Script principal com a criação do DataFrame, tratamento de dados e geração dos gráficos.
- `README.md` → Documentação do projeto.

---

## 🚀 Tecnologias Utilizadas
- [Python](https://www.python.org/)
- [Pandas](https://pandas.pydata.org/)
- [Matplotlib](https://matplotlib.org/)
- [Seaborn](https://seaborn.pydata.org/)

---

## 📊 Análises Realizadas
1. **[Distribuição de vinhos por país](ca://s?q=Distribuicao_de_vinhos_por_pais)**  
   Gráfico de barras mostrando os países com maior número de vinhos.

2. **[Média de pontos por país](ca://s?q=Media_de_pontos_por_pais)**  
   Comparação da qualidade média dos vinhos por país.

3. **[Correlação preço x pontos](ca://s?q=Correlacao_preco_x_pontos)**  
   Scatterplot com regressão para avaliar relação entre preço e pontuação.

4. **[Variedades mais comuns](ca://s?q=Variedades_mais_comuns)**  
   Top 3 variedades de uva mais frequentes.

5. **[Ranking custo-benefício](ca://s?q=Ranking_custo_beneficio_vinhos)**  
   Relação pontos/preço para identificar os melhores vinhos em termos de valor.

---

Os gráficos são gerados automaticamente pelo script `main.py` e incluem:
